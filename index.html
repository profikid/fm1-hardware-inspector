Connection status

Direct USB inspection unavailable in browser-only v1

FM-1 flash inspection uses the JieLi download-mode / vendor-SCSI path. Browser WebUSB cannot reliably claim and operate the mass-storage interface across supported operating systems. This page will not pretend that selecting a USB device is a complete hardware scan.

Expected report fields

model, flash.jedec_id, flash.capacity_bytes, firmware.name/version, update_loader.name/version, bootloader.name/version/status, recovery.available, evidence. See report.schema.json in the repository.

What this page can assess

  • Known flash JEDEC identifiers and nominal capacity
  • Bootloader identity when supplied by a trusted report
  • Firmware / update-loader support evidence
  • Recovery-route status and documented cautions

Safety notes

  • Keep an untouched full-flash backup before any future write operation. A backup may contain Bluetooth pairings, calibration, settings, presets and user data; keep it private.
  • Do not install a bootloader solely because the current one is not identified. “Unreadable” and “missing” are different states.
  • Newer UCUN flash has been reported to behave differently with older firmware that checks only the Puya JEDEC ID. This is a compatibility warning, not proof that every newer-chip unit will fail.
  • An m-bootloader black-screen incident has been reported on a newer-chip device; later 1.3 testing on another newer-chip unit succeeded. Treat untested combinations as unknown, not universally incompatible or safe.
